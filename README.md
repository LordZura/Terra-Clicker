# Clicker Simulator
on scratch, so you can just open this link:
https://scratch.mit.edu/projects/1395909694/

to play, you just have to keep clicking the circle, stack up points, buy upgrades for more points, but keep in mind you are not increasing your clicks, and as you reach certain click counts, you get extra multipliers
there is also prestige, so if you reach certain clicks and you want to restart with permanent multiplier, here you go. each time it gets higher, but the cool thing about prestige is not just passive multiplier, but that it also multiplies base *click* per click, so if you have prestige 1, on one click you will get 2 clicks.
